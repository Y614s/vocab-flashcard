# vocab-flashcard

一个纯前端的背单词应用，支持多模式学习与本地进度保存。

## 功能

- 词书选择：`CET4` / `CET6` / `考研`
- 学习模式：
  - 闪卡模式
  - 图片选义模式
  - 听音选义模式
  - 拼写模式
- 学习计划页（开学前展示今日任务拆分）
- 学习结果页（完成后展示本轮统计）
- 间隔复习（基于熟悉度等级）
- 错题即时回收（答错后会在本轮后续再次出现）
- 每日新词目标
- 学习统计（今日、连续天数、累计学习）
- 本地持久化（`localStorage`）
- 断点续学（中途退出后可继续未完成会话）
- 支持导入自定义单词
- 支持完整数据备份导出/导入
- PWA 基础支持（`manifest` + `service worker`）

## 使用方式

1. 直接在浏览器打开 `index.html`
2. 选择词书、学习模式、每日新词目标
3. 点击“开始今日学习”

如果存在未完成会话，开始时会提示是否继续上次进度。

## 导入格式

在闪卡页面点击右上角导入按钮，文本框中按行输入：

```text
word, 释义
abandon, 放弃
accurate, 精确的
```

说明：

- 使用英文逗号 `,`、中文逗号 `，` 或 Tab 都可以分隔
- 重复单词会自动跳过
- 导入内容只加入当前选中的词书

## 数据备份

- 首页“数据管理”支持导出/导入备份文件
- 备份包含：
  - 学习进度与统计
  - 自定义词库
  - 未完成会话（如有）
- 导入备份会覆盖当前本地数据

## 快捷键

- 闪卡模式：`1/2/3` 选择不认识/模糊/认识，`Enter` 翻卡，`P` 播放发音
- 图片/听音模式：`1/2/3/4` 选项，`P` 播放发音
- 拼写模式：字母键输入，`Backspace` 删除，`H` 提示，`P` 播放发音
- 各模式：`Esc` 返回首页

## 项目文件

- `index.html`：页面结构
- `style.css`：样式
- `script.js`：核心交互逻辑
- `vocab_library.js`：词库数据入口
- `sw.js`：Service Worker 缓存策略
- `manifest.json`：PWA 清单

## 备注

- 当前为前端本地应用，不依赖后端服务
- 统计与学习记录存储在浏览器本地，清理浏览器数据后会丢失
